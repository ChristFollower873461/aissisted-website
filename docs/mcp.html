Model Context Protocol

Public service facts and availability for AI agents.

AIssisted Consulting exposes a public MCP endpoint at https://aissistedconsulting.com/mcp. Agents may explain the two implementation lanes, read the published $225 plan, and check open appointment windows.

Direct MCP booking is disabled. The human reviews the exact Workflow Map & First-Build Plan terms, accepts them, and completes Stripe Checkout on the booking page.

Available tools

Read before acting.

  • list_services — two implementation lanes, Fit Call, and paid plan.
  • get_business_info — founder, location, contact, audience, and service area.
  • get_quote — published plan fee or separate-scope boundary.
  • check_availability — open windows for workflow-map-first-build-plan.
  • get_booking_status — status for an existing user-supplied booking id.

Financial boundary

No agent-completed purchase.

The website does not collect card details. The human must review the exact release, offer, fee, terms version, and terms hash before Stripe Checkout. The $225 v2 fee is for the session and plan and creates no implementation credit.
